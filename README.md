# DocketField rebrand brainstorm · 20 direction prototypes

**Live preview** → [https://enkarii.github.io/docketfield-rebrand-preview/](https://enkarii.github.io/docketfield-rebrand-preview/)

These are static HTML mockups exploring 20 alternative visual + flow + structural directions for a DocketField rebrand. Created 2026-05-27 for solo founder + partner review.

This repo is **prototype-only** — no production code, no business logic, no secrets. The main DocketField application lives in a separate private repo and is unaffected by anything in here.

## How to review

1. Open [`index.html`](https://enkarii.github.io/docketfield-rebrand-preview/) — the comparison hub.
2. The 20 directions are split into two sets:
   - **v1 — paint variations (D0–D10)**: same article-publication scaffold, ten different visual treatments.
   - **v2 — flow + structure variations (D11–D20)**: ten *fundamentally different* products (chat-led, feed-led, Q&A, video, source-annotation, slow-web, live-board, wiki-hybrid, visual-curation, collaborative-brain). This is where the spirit re-anchor lives.
3. Each direction has two surfaces — a public landing (`main.html`) and a direction-specific contributor/admin surface (`backend.html`).

## What's *not* here

- No production source code from the DocketField application.
- No customer or contributor data — every name in the mockups (Sam Ahmadi, Alex Patel, Maya Khurana, etc.) is an illustrative placeholder cast.
- No financial figures from any real Stripe / accounting data.
- Tailwind + Google Fonts are loaded via CDN without Subresource Integrity for prototype velocity; production rollout of any chosen direction would self-host + add SRI hashes.

## Re-anchored spirit (the brief)

"This isn't a PhD hangout. It's for intellectuals in all walks of life — professional or not in that field — to contribute if there's value."

The v2 set (D11–D20) is structurally designed around that anchor — a truck driver's loading-dock observation, a high-school teacher's question, an ex-Treasury parent reading the NPRM at nap-time, a federal-grants accountant, a freight forwarder — all appear as *lead* voices in the prototypes, not marginal ones.
