House rules

About this prototype

This is direction D21 in the DocketField rebrand brainstorm. It is deliberately built without webfonts, without a design system, and without custom layout primitives — pure HTML defaults, system serif, default link colors, table layout. The aesthetic lineage is the brutalist-web tradition (Hacker News, text.npr.org, the old Are.na, Drew Schuster, Jonas Lund). The argument is that a serious community of thinking people doesn't need a designed surface to be taken seriously — in fact, the absence of designerly polish can read as “this is real, not marketing.”
