Five wildcards · five aesthetic universes · same content

Five genuinely different worlds. Same community. Pick a universe.

After two earlier rounds (twenty paint variations, then three polished in the same modern-editorial school of taste), the operator was right: those all looked the same. This round actually swings. Five directions occupying entirely different design lineages — brutalist text-web, Italian fashion magazine, riso-print zine, broadsheet newspaper, playful atelier — all rendering the same Sam Ahmadi loading-dock story so the visual differences are pure visual differences.

⚑ Wildcards · v3

Five aesthetic universes

5 directions · 1 main page each · same content, different worlds
D21 · BRUTALIST WEB
The Lobby

System fonts, default browser styling, table-as-layout, default blue links. The brutalist-web lineage: Hacker News, text.npr.org, old Are.na. The argument is that a serious community doesn't need designed surface to be taken seriously.

D22 · EDITORIAL MAXIMUM
THE LOBBY

032c / Bottega Veneta / SSENSE. One typeface. Two scales — giant + tiny. No accent color. Eighty percent white space. Italian fashion-magazine discipline applied to a community feed.

D23 · RISOGRAPH ZINE
The Lobby

Two-color riso print: ink + fluorescent pink, on cream paper with halftone dots. Weird display serif (Fraunces wonk italic). Slight rotations. Hand-feel. Asterisk Magazine energy.

D24 · BROADSHEET
The Lobby

Financial Times / WSJ classic. Real broadsheet typography (Playfair Display + Source Serif 4). Multi-column lead with drop cap. Market-data table for live activity. Salmon paper. Editorial column. Subscribe banner.

D25 · PLAYFUL ATELIER
The Lobby

Recurse Center / Glitch / Robin Sloan warmth. Pastel multi-color palette (peach, sage, butter, sky, plum). Round corners, hand-drawn SVG illustration, soft shadows. Real joy without twee.

⚑ Re-anchored spirit · constant across all directions

"This isn't a PhD hangout. It's for intellectuals in all walks of life — professional or not in that field — to contribute if there's value."

Same five-voice cast threaded through every wildcard: Sam Ahmadi (truck driver, loading-dock signal), Alex Patel (Brookhaven researcher off-duty), Maya Khurana (regional-bank compliance officer), Diego Torres (high-school chemistry teacher), Jess Oduya (ex-Treasury parent reading NPRMs at nap-time). The visual language changes; the spirit doesn't.
